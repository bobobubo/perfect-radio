# Changelog

## 0.1.1

- Initial distributable Perfect Radio release.
- Built-in XML station catalogue.
- Select entity for choosing a station.
- Zero-configuration Lovelace card.
- Browser-local audio playback with Play / Stop controls.
- Automatic stream switching when the selected station changes during playback.
- Home Assistant Play / Stop actions for `media_player` targets.
- Automatic Lovelace resource registration.
- SHA-256 frontend cache busting.
